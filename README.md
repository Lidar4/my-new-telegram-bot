# 🤖 my-new-telegram-bot

একটি সম্পূর্ণ নতুন, নিরাপদ এবং আধুনিক **Telegram Bot** প্রজেক্ট—যা তৈরি করা হয়েছে **Node.js**, **TypeScript** এবং **GrammY** লাইব্রেরি ব্যবহার করে।

---

## 📁 প্রজেক্টের ফাইল কাঠামো

```text
my-new-telegram-bot/
├── .env.example        # এনভায়রনমেন্ট ভেরিয়েবলের সুরক্ষিত ডামি টেমপ্লেট
├── .gitignore           # গিট ও গিটহাবে সিক্রেট ফাইল আপলোড রোধের নিয়মাবলী
├── README.md            # সম্পূর্ণ প্রজেক্ট ডকুমেন্টেশন ও সেটআপ গাইড
├── package.json         # প্রজেক্ট মেটাডাটা ও ডিপেনডেন্সি তালিকা
├── tsconfig.json        # টাইপস্ক্রিপ্ট কনফিগারেশন
└── src/
    └── index.ts         # বটের মূল নিরাপদ সোর্স কোড (Start & Message Handlers)
```

---

## 🔒 নিরাপত্তা নীতিমালা (Security Rules)

1. **টোকেন হার্ডকোড নিষেধ:** কোডের কোনো ফাইলে কখনোই আসল Telegram Bot Token সরাসরি লেখা যাবে না।
2. **সার্ভার-সাইড এনভায়রনমেন্ট:** বট শুধুমাত্র `process.env.TELEGRAM_BOT_TOKEN` থেকে টোকেন গ্রহণ করে।
3. **গিট ফিল্টারিং:** `.gitignore` ফাইলের মাধ্যমে নিশ্চিত করা হয়েছে যাতে `.env` বা কোনো সিক্রেট ফাইল ভুলবশতও GitHub-এ আপলোড না হয়।
4. **লগ সুরক্ষা:** কোডের এরর হ্যান্ডলার বা কনসোল লগে কোনো অবস্থাতেই সম্পূর্ণ টোকেন বা সংবেদনশীল তথ্য প্রদর্শিত হবে না।

## 🛠️ সেটআপ ও রান করার নিয়মাবলী

### ধাপ ১: Telegram Bot Token সংগ্রহ করা
1. Telegram অ্যাপে গিয়ে **`@BotFather`**-এ প্রবেশ করুন।
2. চ্যাটে `/newbot` লিখে সেন্ড করুন।
3. আপনার বটের জন্য একটি নাম ও ইউজারনেম (যেমন: `my_test_bot`) দিন।
4. BotFather আপনাকে একটি গোপন **HTTP API Token** প্রদান করবে।

### ধাপ ২: লোকাল ফাইলে টোকেন সংরক্ষণ
প্রজেক্টের রুট ডিরেক্টরিতে `.env.example` ফাইলটি কপি করে `.env` তৈরি করুন:

```bash
cp .env.example .env
```

এখন আপনার কম্পিউটারে তৈরি হওয়া `.env` ফাইলটি এডিট করে আপনার গোপন টোকেনটি বসান:

```env
TELEGRAM_BOT_TOKEN="আপনার_আসল_বট_টোকেন"
```

> **সতর্কতা:** `.env` ফাইলটি শুধুমাত্র আপনার লোকাল কম্পিউটারে বা হোস্টিং সার্ভারে থাকবে। এটি কখনো GitHub-এ যাবে না।

### ধাপ ৩: ডিপেনডেন্সি ইনস্টল করা
```bash
npm install
```

### ধাপ ৪: বট চালু করা
বট রান করতে নিচের কমান্ডটি চালান:

```bash
npm run bot
```

সফলভাবে চালু হলে কনসোলে নিচের মেসেজটি দেখতে পাবেন:
```text
✅ বট সফলভাবে চালু হয়েছে!
🤖 বটের নাম: My Bot
🔗 বটের ইউজারনেম: @my_test_bot
```

## 🧪 বট পরীক্ষা করার নিয়ম

1. আপনার Telegram অ্যাপে আপনার বটের ইউজারনেম লিখে সার্চ করে চ্যাট ওপেন করুন।
2. **/start** কমান্ড পাঠিয়ে পরীক্ষা করুন। বট স্বাগতম বার্তা দিয়ে উত্তর দেবে।
3. যেকোনো সাধারণ টেক্সট মেসেজ (যেমন: "Hello") লিখে পাঠান। বট আপনার মেসেজ গ্রহণের স্বীকৃতি জানাবে।

---

## 🚀 হোস্টিং প্ল্যাটফর্মে চালানোর নিয়ম

বটটি কোনো ক্লাউড হোস্টিংয়ে (যেমন: Render, Railway, বা VPS) ২৪/৭ চালু রাখার জন্য:
1. কোডটি আপনার গিটহাবে পুশ করুন (নিশ্চিত থাকুন যে `.gitignore` ঠিক আছে এবং `.env` আপলোড হয়নি)।
2. হোস্টিং প্রোভাইডারের ড্যাশবোর্ডে গিয়ে **Environment Variables** সেকশনে যান।
3. Key ঘরে লিখুন: `TELEGRAM_BOT_TOKEN`
4. Value ঘরে আপনার বটের আসল গোপন টোকেনটি প্রবেশ করান।
5. স্টার্ট কমান্ড হিসেবে `npm start` অথবা `npm run bot` দিন।
